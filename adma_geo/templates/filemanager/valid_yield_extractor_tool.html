Valid Yield Extractor

Clean yield data by filtering harvest points to valid application areas

This tool processes treatment plots, as-applied data, and harvest data to generate:

  • Valid Application Area (VAA) - Areas where application rates match target rates
  • Valid Harvest Area (VHA) - Harvest points within valid application areas
  • Harvest Strips - Strip-level analysis of harvest data
  • Clean Yield Points - Filtered yield points for downstream analysis
  • Summary CSV - Tabular summary of results
  • Visualizations - PNG plots of the analysis

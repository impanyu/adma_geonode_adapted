SI Tool (Sufficiency Index Calculator)

Calculate Sufficiency Index values from buffer sectors and NDRE data

This tool evaluates crop nitrogen sufficiency by comparing NDRE values against reference values. Supports four workflow modes:

  • STANDARD + UAV - Buffer sectors + NDRE shapefile + CSV
  • STANDARD + Satellite - Buffer sectors + NIR/RedEdge GeoTIFFs + CSV
  • SBF + UAV - Buffer sectors + Indicator blocks + NDRE shapefile + CSV
  • SBF + Satellite - Buffer sectors + Indicator blocks + NIR/RedEdge GeoTIFFs + CSV

{% extends 'filemanager/_native_tool_base.html' %} {% block tool_icon %}fa-border-all{% endblock %} {% block tool_tagline %}Turn machine-logged points into the ground each one covered{% endblock %} {% block run_url %}{% url 'filemanager:run_point_to_polygon' %}{% endblock %} {% block tool_blurb %}
Converts machine-logged points — yield, seeding, NH3, fertigation — into a polygon for the ground covered at each point, from the swath width, distance, heading and Y offset recorded with it. Polygons along a pass share edges, and reduced-width passes shift toward the cut side. Each polygon keeps the point's attributes and adds its area and how much of it overlaps ground already covered (OVLP_PCT, flagged at 25%), for true acreage, headland and pass-end overlaps, yield cleaning, and matching yield to applied rates by area.
{% endblock %} {% block tool_inputs %}
A shapefile, GeoJSON or GeoPackage of logged points, or a CSV with longitude/latitude columns.
Choose a point file and its columns will appear here, with the likely ones already picked.
Polygon width. Required.
Length along the pass. Or compute it from point spacing.
Direction of travel. Or compute it from consecutive points.
Smoothing evens out GPS jitter in the heading without mixing passes.
Only if the file has no .prj, or a CSV's coordinates are not longitude/latitude.
